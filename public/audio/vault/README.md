# Vault audio assets

| File | Duration | When it plays |
|------|----------|---------------|
| `vault-round-log.mp3` | ~1s | Athlete taps **Log round** (local confirmation) |
| `vault-session-start.mp3` | ~6s | Host starts the session — every client plays it when the session enters **setup** |

These are loaded via the Web Audio API on unlock and replace the synthesized ignition / round-log cues when available.
